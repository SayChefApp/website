# 🍳 SayChef

> **Speak your recipes. We'll organize the rest.**

SayChef is a voice-first AI recipe manager that transforms spoken recipes into beautifully organized cookbooks. Whether you're preserving family recipes, discovering meals from ingredients you already have, or cooking hands-free, SayChef makes cooking simpler.

🌐 **Website:** https://saychef.online

# Why We Built SayChef

Typing recipes while cooking is frustrating.

Family recipes get lost.

Recipe cards fade.

Notes apps become cluttered.

SayChef was built to preserve recipes, simplify cooking, and make it effortless to build a personal cookbook using your voice.
